# 🤝 Contribuer à BatLife

Merci de votre intérêt pour BatLife ! 💚  
Toute contribution est la bienvenue, quel que soit votre niveau.

---

## 🌟 Comment contribuer ?

Il existe **plusieurs façons** d'aider le projet, même sans savoir coder !

---

### 🐛 Signaler un bug

Vous avez trouvé un problème ? Merci de nous le dire !

1. Allez dans l'onglet [Issues](https://github.com/contactbatlife-debug/batlife/issues)
2. Cliquez sur **"New Issue"**
3. Décrivez :
   - Ce que vous avez fait
   - Ce qui s'est passé
   - Ce qui aurait dû se passer
   - Votre appareil (iPhone, Android, PC...)
   - Une capture d'écran si possible

---

### 💡 Proposer une idée

Une fonctionnalité manque ? Vous avez une idée ?

1. Ouvrez une [Issue](https://github.com/contactbatlife-debug/batlife/issues)
2. Ajoutez le tag **"enhancement"**
3. Expliquez votre idée simplement

---

### 🌍 Aider à traduire

BatLife est disponible en **5 langues** : FR, EN, ES, DE, NL.

Vous parlez une autre langue ? Aidez-nous à ajouter :
- 🇮🇹 Italien
- 🇵🇹 Portugais
- 🇵🇱 Polonais
- 🇯🇵 Japonais
- ... ou toute autre langue !

Ouvrez une Issue avec le tag **"translation"** et on vous guide.

---

Vous êtes développeur ? Génial !

- Node.js 18+
- npm ou yarn
- Git

1. **Forkez** le projet (bouton en haut à droite sur GitHub)
2. **Clonez** votre fork :
   ```bash
   git clone https://github.com/VOTRE-NOM/batlife.git
   cd batlife
