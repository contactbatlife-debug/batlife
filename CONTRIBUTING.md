# 🤝 Contribuer à BatLife

Merci de votre intérêt pour BatLife ! 💚  
Toute contribution est la bienvenue, quel que soit votre niveau.

---

## 🌟 Comment contribuer ?

Il existe **plusieurs façons** d'aider le projet, même sans savoir coder !

---

### 🐛 Signaler un bug

Vous avez trouvé un problème ? Merci de nous le dire !

1. Allez dans l'onglet [Issues](https://github.com/contactbatlife-debug/batlife/issues)
2. Cliquez sur **"New Issue"**
3. Décrivez :
   - Ce que vous avez fait
   - Ce qui s'est passé
   - Ce qui aurait dû se passer
   - Votre appareil (iPhone, Android, PC...)
   - Une capture d'écran si possible

---

### 💡 Proposer une idée

Une fonctionnalité manque ? Vous avez une idée ?

1. Ouvrez une Issue
2. Ajoutez le tag **"enhancement"**
3. Expliquez votre idée simplement

---

### 🌍 Aider à traduire

BatLife est disponible en **5 langues** : FR, EN, ES, DE, NL.

Vous parlez une autre langue ? Aidez-nous à ajouter d'autres langues :
Italien, Portugais, Polonais, Japonais, etc.

Ouvrez une Issue avec le tag **"translation"** et on vous guide.

---

### 💻 Contribuer au code

Vous êtes développeur ? Génial !

**Prérequis :**
- Node.js 18+
- npm ou yarn
- Git

**Étapes :**

1. Forkez le projet
2. Clonez votre fork
3. Installez les dépendances avec npm install
4. Créez une branche
5. Codez votre amélioration
6. Testez en local avec npm run dev
7. Commitez et poussez vos changements
8. Ouvrez une Pull Request sur GitHub

---

## 📏 Règles simples

- 🎯 Un commit = un changement clair
- 💬 Messages de commit en français ou anglais
- 🎨 Respecter le style de code existant (React + Tailwind)
- 🌍 Si vous ajoutez du texte visible, pensez aux 5 langues
- 📱 Toujours tester sur mobile ET desktop
- ✨ Rester dans l'esprit BatLife : simple, gratuit, sans pub, respectueux de la vie privée

---

## 🚫 Ce qu'on n'accepte PAS

- ❌ Publicité ou tracking
- ❌ Collecte de données personnelles
- ❌ Dépendances lourdes non justifiées
- ❌ Fonctionnalités payantes
