## [1.0.0] - 2025-01-XX

### 🚀 Première version publique

### ✨ Fonctionnalités
- 🔋 Suivi de charge intelligent avec repos de stabilisation
- 📊 Statistiques détaillées (Wh/km, autonomie, SoH)
- 🏆 Système de badges et progression
- 🌍 Support de 4 langues (FR, EN, ES, DE)
- 📱 PWA installable sur mobile et desktop
- 💾 Export/Import JSON pour sauvegarde
- 🔒 100% local — aucune donnée collectée
- 🎨 Design glassmorphism moderne

### 🛠️ Stack technique
- React 18 + Vite
- Tailwind CSS
- Recharts pour les graphiques
- LocalStorage (zéro serveur)
- PWA avec Service Worker
- Hébergement Cloudflare Pages
